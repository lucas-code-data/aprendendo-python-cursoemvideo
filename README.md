# aprendendo-python-cursoemvideo
Minha primeira etapa, aprendendo Python com o professor Gustavo Guanabara.

---

## 📖 Organização do Repositório

O curso é dividido em três grandes módulos (Mundos). Os códigos estão organizados nas seguintes pastas:

* `mundo-01`: Fundamentos da linguagem, tratamento de dados e as primeiras estruturas aritméticas.
* `mundo-02`: Estruturas de controle (condições if/elif/else e repetições for e while).
* `mundo-03`: Estruturas avançadas (tuplas, listas, dicionários, funções, módulos e tratamento de erros).
